# RateHub — Store Rating Platform

A full-stack store rating platform built with **React.js, Node.js, Express.js, and PostgreSQL**.

RateHub provides role-based access for **System Administrators, Normal Users, and Store Owners**.

## ✨ Features

### Admin
- Dashboard with users, stores, and ratings statistics
- Add and manage users and stores
- Search, filter, and sort records
- View store ratings

### Normal User
- Register and login
- Search and discover stores
- Submit ratings from **1–5**
- Modify submitted ratings
- Update password

### Store Owner
- View store average rating
- View rating breakdown
- View customers who rated the store
- Monitor customer feedback
- Update password

## 🛠️ Tech Stack

**Frontend:** React.js, React Router, Axios, Vite  
**Backend:** Node.js, Express.js, JWT, bcrypt  
**Database:** PostgreSQL  
**Tools:** Docker, Git, GitHub
